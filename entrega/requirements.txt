# POR QUÉ ESTE ARCHIVO ES CORTO, Y POR QUÉ ESO ES DELIBERADO
#
# §1.4 define `generador.py` como un «Script Python que utilice el índice, lea
# el archivo de consultas y genere el archivo de resultados». **Usa el índice ya
# construido; no reconstruye el corpus.** Todo el trabajo de extracción, OCR,
# limpieza, chunking y codificación ocurrió aguas arriba y su resultado va
# horneado dentro de `base_vectorial/`.
#
# Consecuencia: aquí NO hacen falta `pdfplumber`, `PyMuPDF`, `pytesseract`,
# `openpyxl`, `mapbox-vector-tile` ni el binario de Tesseract. Declararlos sería
# darle a quien reproduzca la entrega más superficie para que algo falle, y
# **cualquier fallo de instalación impide correr el generador**, que es
# exactamente lo que §1.4 castiga con la exclusión.
#
# Los cuatro paquetes de abajo son los ÚNICOS imports de terceros en toda la
# cadena que `generador.py` arrastra. Verificado leyendo los imports de
# `generador.py`, `retrieval/consultas.py`, `retrieval/search.py`,
# `retrieval/fragmentos.py`, `embedding/encoder.py`, `chunking/chunker.py` y
# `core/chunk.py`: los tres últimos no importan nada de terceros.
#
# La lista completa que usamos para CONSTRUIR el índice está en el
# `requirements.txt` de la raíz del repositorio, y no hace falta aquí.
#
# ─────────────────────────────────────────────────────────────────────────────
# ⚠️ EL MODELO SE DESCARGA EN TIEMPO DE EJECUCIÓN
#
# `sentence-transformers` baja `BAAI/bge-m3` (4,35 GB) de HuggingFace la primera
# vez. La **revisión está fijada por sha** en `src/embedding/encoder.py`
# (`5617a9f61b028005a4858fdac845db406aefb181`): sin eso se podría descargar otra
# versión del modelo, los vectores de la consulta dejarían de vivir en el mismo
# espacio que los del índice y el ranking cambiaría **sin dar ningún error**.
#
# Codificar las 50 consultas cuesta ~8 min en CPU y segundos en GPU.
#
# ⚠️ `faiss-cpu`, NUNCA `faiss-gpu`: esto se ejecuta en la máquina de quien
# evalúa y puede no haber GPU. Un índice plano (`IndexFlatIP`) no se entrena, así
# que la GPU no aportaría nada.
#
# ⚠️ NO añadir `pathlib`: el paquete `pathlib` de PyPI es un backport viejo que
# puede sombrear el `pathlib` de la librería estándar. Estuvo aquí por error.
